# Open-Shelf

Stories shared quietly, without pressure.

Open-Shelf is a lightweight static publishing platform built for sharing long-form written content in a simple and distraction-free format.

The project focuses on readability, clean structure, and easy content management rather than heavy frameworks or complex backend systems.

## Features

* Static long-form content publishing
* Simple chapter-based structure
* Lightweight and responsive design
* Easy deployment through Netlify
* Minimal and distraction-free reading experience

## Tech Stack

* HTML
* CSS
* Git
* Netlify

## Purpose

This repository primarily serves as the deployment and content-management source for the live Open-Shelf website.

The platform was built to create a quiet reading-focused experience without unnecessary clutter or aggressive UI patterns.
